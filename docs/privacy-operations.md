# 개인정보 처리 운영 확인 및 요청 처리 안내

이 문서는 운영 준비를 위한 체크리스트입니다. 확인되지 않은 항목을 처리방침의 확정 사실로 기재하지 않습니다.

## 배포 전 운영자 확인

- 개인정보 보호책임자의 이름 및 연락처, 요청 접수 담당자와 회신 방법을 확정한다. 기존 문의 경로는 Instagram @andflow.studio DM이다. 해당 계정의 실제 접근 가능 여부와 상시 확인 담당자를 운영자가 확인한다.
- 카카오 개발자 콘솔의 동의항목과 간편가입 약관 설정, 각 필수·선택 여부 및 실제 동의 화면을 확인한다. 개인정보 수집의 법적 근거와 별도 동의의 필요성, 필요한 경우 동의 항목·버전·이력 보존을 검토한다.
- 실제 배포의 웹 호스팅 사업자 및 서비스 지역, DB 사업자·프로젝트 지역, 데이터 접근 주체, 수탁·재수탁과 계약을 확인한다. 로컬 연결 설정은 운영 환경의 증거가 아니다.
- 개인정보 국외이전 여부와 이전받는 자, 국가, 시점·방법, 항목, 목적과 보유 기간, 적용 근거 및 필요한 절차를 확인한다. 외부 제공과 위탁 여부를 별도로 검토한다.
- 호스팅 및 DB의 접속 로그·백업·복제의 저장 지역과 보존 기간, 삭제 및 복원 후 재삭제 절차를 확인한다. 해당 데이터에 IP 등 개인정보가 있는지 확인한다.
- 양말 공유 화면에 표시되는 닉네임과 수신자에게 표시되는 편지 내용의 법적 처리 근거를 확인한다. 사용자가 입력한 편지에는 추가 개인정보가 포함될 수 있다.
- 서비스 종료 후 일반 데이터 삭제 기간(2027-01-16~2027-01-31 KST)에 대한 책임자·실행 방식·검증을 확정한다. 법정 보존이 필요한 정보는 대상과 근거·기간을 별도 확인한다.
- 개인정보 처리방침의 [확인 필요] 항목과 약관의 실제 시행일을 확정한 뒤 시행일을 명시한다. 현재 약관의 2026-11-15는 초안 표기이며 실제 시행일이라고 단정하지 않는다.

## 개인정보 요청 접수

1. 기존 안내된 Instagram @andflow.studio DM에서 요청 종류와 회신 방법을 접수한다. 계정 접속과 접수 가능 여부는 운영자가 사전에 확인해야 한다.
2. 비밀번호, 카카오 인증코드, 편지 본문이나 신분증 사진을 DM으로 요구하지 않는다. 담당자와 안전한 본인 확인·회신 절차가 정해질 때까지 요청이 처리됐다고 안내하지 않는다.
3. 요청 내용과 처리 기한, 법적 제한 여부를 검토하고 필요한 범위에서 본인 확인 후 열람·정정·삭제·처리정지를 처리한다. 다른 이용자의 개인정보가 함께 포함된 경우 분리·제한 여부를 검토한다.
4. 완료 여부와 처리하지 못한 부분을 안전한 경로로 회신한다. 요청 처리 기록의 보유 범위와 기간도 확정해야 한다.

## 탈퇴 기능

현재 탈퇴 API는 중단되어 있다. 기존 스키마에서는 회원 삭제가 작성한 편지 삭제로 이어질 수 있으며, 관련 계정·편지·신고 및 백업 정책과 카카오 연결 해제 실패 시 복구를 확인하기 전 활성화하지 않는다. 카카오에서 직접 연결 해제하는 경우에 대한 웹훅도 준비되어 있지 않다.
